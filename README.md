# Remote HVRC Management

I built this project to control an HVRC unit via an ESP32 Web Server + a relay which interfaced with the HVRC unit. This is my first project using platform.io as well as my first project working with an ESP32. The project is broken up into multiple compilation contexts in the platformio.ini file. src/main.cpp is only responsible for including the main code based on compiler directives supplied by the different build contexts in platformio.ini. Lib/Projects contains the actual main files for each project, called main.hpp. The Blink Project is a sandbox application where I can play around with libraries and test drivers. The server project contains the application which interfaces with the HVRC unit. This is intended to be a wired in board which does not need to worry about battery power. I have plans for additional projects which will use ESP32s as a wifi client to remotely translate push button inputs into commands similar to what are found on the webpage.
